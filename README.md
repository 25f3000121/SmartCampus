# Smart Campus

Smart Campus is a web-based campus complaint and service management system.

🌐 **Live Website:**
https://25f3000121.github.io/SmartCampus/

## Features

- Student login and registration
- Complaint management
- Service request management
- Organization Admin
- Super Admin
- Multi-customer and multi-organization support

## Technologies

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL
